# Teste Técnico — Mural de Enquetes ao Vivo (FantasyDraft)

Aplicação full stack onde usuários criam enquetes e votam, com resultados atualizados em tempo real via WebSocket.

## Stack
- Backend: Laravel 11 (PHP 8.3) + PostgreSQL
- Frontend: React 18 (Vite)
- Tempo real: Node.js + ws
